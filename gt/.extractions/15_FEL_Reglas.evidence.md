## Supersessions of the 2018-vintage corpus (current-authority values)

1. **Anulación window:** 2018-era value (and v1.5, 20/12/2019): "no más de 5 días en el pasado". **Current (v1.5.4 Rev.1 07/12/2020 → 3.16.7.1):** anulación allowed until the *due date of the IVA monthly declaration for the emission period*; additionally blocked if the period is prescribed (5.5.1.b) or NC/ND/constancia/retención/Asiste-Libros/LET/Planilla-IVA associations exist (3.16.2, 3.17.2).
2. **NC/ND via a different certificador:** allowed since v1.6 (3.7.1.6 explicitly "Se deja sin efecto"). Same for anulaciones via another certificador (3.16.5 note). 2018 manual implied certificador matching — superseded.
3. **Fecha emisión:** current = ≤5 días back (counted from day after emission) + future dates only within the same calendar month (2.2.1.1–2 + aclaración); constancias CIVA/CAIS exempt from the 5-day rule (v1.7). 2018 casos wording confirmed in substance, now with explicit same-month-future rationale.
4. **Frase tipo 4 scenario catalog:** 2018 casos treated scenarios >12 as error; **current catalog runs 1–35 (34 absent) plus esc. 36 cited in 2.6.1.27** — scenario lists for FACT/FCAM now explicitly enumerated in 2.6.1.9.
5. **NC/ND origin types:** still FACT/FCAM only (3.7.1.2) — 2018 value NOT superseded; paper/FACE origins still gated by Código Tipo list (OQ-9).
6. **CF threshold:** Q2,500.00 Gran Total (GTQ or FX-converted) — appears in 2.2.4.11, 2.2.5.6, 2.2.7.2, 2.19.1.2, 2.19.2.4.
7. **Contingencia:** current procedure requires XML per current XSD + "Documento en contingencia" title + Número de Acceso (9 digits) + SAT-verifier footer + aviso (Agencia Virtual "Aviso de Contingencia" or efactura@sat.gob.gt) + immediate re-send upon reconnection (4.1). Any 2018 manual stating a fixed re-certification hour-window is superseded by "de forma inmediata" (verify doc 19's exact wording against this).
8. **New in v2.0 (absent from all 2018 docs):** FEPE/FARP/FCRP/FPEC/FCPC, DestinodelaVenta, frases 10/11/12, complemento Retenc. Factura Específica (ICT 1.5%), establecimiento codes 3694–3696/1696/885,_afiliación columns PRI/PEC.
9. **FESP retentions:** ISR 5% per Dec 10-2012 (as modified by Dec 4-2019 per changelog v1.2); IVA retención = total IVA of the document (3.5) — 2018 FESP values re-based.
10. **Timbre de prensa on NC/ND:** v1.1 (08/01/2019) already removed the NCRE tasa-municipal validation; current matrix (2.4.1) has NDEB/NCRE = SI for TDP but NO for Tasa Municipal and Tarifa Portuaria.
