- **OQ-2:** Record-level field layouts (book grid columns, resumen totals, papel-entry forms, carga-masiva file template, report column sets) are **images with no text layer** in all four manuals — layout tables p. e.g. `57_` pp.10-16, `58_` pp.11-17, `82_` pp.10-15, `59_` pp.4-15 are NOT extractable; a layout source (portal normativa or text-layer document) must be acquired before any export-layout CR.
- **OQ-3:** **No LET-creating/regulating SAT resolution number is printed anywhere** in the four manuals; the only normativa hooks printed are D27-92 (Caps. V/VI/VIII/IX; art. 57 "D"), D10-2012 (arts. 14-42, 38) and Ley de Timbres Fiscales art. 5 num. 4 (EVID-474). The known resolution-acquisition gap gains no new lead from these files; regime parameters quoted in glossaries (5%, 4%/5%, 12%, Q150k, Q3M) are secondary prints to be verified against D27-92/D10-2012 primary evidence.
- **OQ-4:** Deadline rules largely absent: `57_`/`58_` print **no** cierre/declaration deadline; `82_` prints only the electrónico-regime **4%-within-10-días-hábiles / 5%-after** tariff-deadline (EVID-468); `59_`'s system marks "en tiempo o fuera de tiempo" without printing the rule.
