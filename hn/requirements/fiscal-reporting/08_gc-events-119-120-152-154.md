## 1. Purpose

This file defines the functional requirements for the Honduras fiscal-reporting
**event-declaration family** of cluster F8: the four OVI event surfaces that
sit outside the monthly DJIMR/DMC cycle and the 30-abril annual package —
(a) **código 119**, the *declaración jurada del Impuesto sobre Ganancias de
Capital* (capital-gains sworn declaration, 10% *impuesto único*): the
per-transaction event ledger, the 10-*días hábiles* payment clock from
perception of the agreed value, the *Boletín de Pago Libre* payment-only slip,
and the April-30 annual consolidating declaration; (b) **código 120**, the
ZOLITUR 4% substitute regime declaration (*Zona Libre Turística del
Departamento de Islas de la Bahía*, territory minus the Cayos Cochinos
archipelago) with its *alta/eventual* non-recurrent channels; (c) **código
152**, the *Impuesto sobre Tradición de Bienes Inmuebles* (onerous real-estate
transfer tax, 1.5%, seller-borne, 3-day clock from notarial authorization,
anonymous no-login filing); and (d) **código 154 / SER-154**, the
*Impuesto de Revaluación de Activos* declaration (6% *pago único y
definitivo* on the elective revaluation increment).

It does **not** own: the GC 10% LAW mechanics — rate, scope, base formula
(max(agreed, market) − *mejoras* − legalization costs), same-year loss
netting, non-resident buyer-retention rate authority and the State-as-payor
retention — owned by `../taxation/03_isr-rates-gains-minimum.md`
(HN-TAX-FR-093..104) and consumed here BY ID, never re-derived; the
revaluation accounting law side (election, *Superávit de Capital por
Revaluación de Activos*, non-deductibility) — `../taxation/05_d17-2010-family.md`
(HN-TAX-FR-184..186); the OVI/SW filing chassis (login, *borrador*,
*juramento*, acuse + QR, rectificativa state machine, boletín expiry) —
file 01 of this wave (cluster F1), consumed by id; the código 138 DJIMR
eventual filing for non-resident retentions — file 02 (cluster F2; deadline
duality `38_ OQ-2` lives there); the 102/103 Sección B targets that consume
119/120 bases — file 07 (cluster F7); the 542 rent-contracts informativa —
file 10 (cluster F10); and the annual-close package membership itself
(74_ RESUMEN) — file 07.

### 3.1 Código 119 — GC declaration surfaces (the 10% law side = taxation/03 by id)

- **HN-FREP-FR-266:** The system shall maintain a per-transaction
  *ganancias de capital* event ledger feeding código 119 — one record per
  disposal outside the seller's habitual trading (*giro habitual*), with
  fields: transaction date, perception date of the agreed value, asset class,
  agreed value, market value, documented improvements (*mejoras
  comprobadas*), legalization costs, computed taxable result and tax
  (consumed by id from taxation/03 HN-TAX-FR-093..096), seller residency,
  State-as-payor flag — and shall present/rectify/pay every declaration of
  this file through the OVI chassis owned by file 01 (acuse + QR compliance
  evidence, boletín with expiry, rectificativa per CT Art. 117 with
  side-by-side strikethrough UI, Excel detail download from estado "Original
  OT. Aprobada OT"). (LB-001; LB-008; LB-009; EV29:EVID-091; EV29:EVID-102;
  EV29:EVID-103)
- **HN-FREP-FR-267:** The system shall schedule each GC transaction's
  payment within ten (10) *días hábiles* (business days) following the date
  the agreed value was perceived (*en que se percibió el valor pactado*) —
  a per-transaction clock on the HN business-day calendar — and shall
  generate the payment-only *Boletín de Pago Libre* (código 119) as a slip
  DISTINCT from the determinativa annual declaration (74_ package names
  both). (LB-001; EV29:EVID-102; EV29:EVID-110)
- **HN-FREP-FR-268:** The system shall consolidate the fiscal year's GC
  transactions into the annual declaración jurada 119 due at the latest
  April 30 of the following fiscal year (*a más tardar el 30 de abril del
  año siguiente fiscal que se declare*), as a dated due-date row with
  next-business-day shift consumed from the file-07/file-01 calendar
  contract. (LB-001; EV29:EVID-102; EV29:EVID-110)
- **HN-FREP-FR-269:** The system shall implement form 119's structure:
  sections *Ingresos netos para el período / Deducciones para el período /
  Determinación del impuesto / Créditos*; income lines by asset class —
  *venta o permuta de bienes inmuebles / bienes muebles / títulos valores /
  derechos / Premios por juegos de azar, Sorteos o Rifas / Otras ganancias*
  — with mirrored deduction lines; determination = (total GC income − total
  allowed deductions = *utilidad*) × 10% auto-computed; credit panel =
  *pagos realizados para el período, Excedente del período anterior, Importe
  a compensar, Cesiones de crédito y otros créditos*. (LB-001; LB-002;
  EV29:EVID-103)
- **HN-FREP-FR-270:** The system shall support the year+month period
  selector ("Seleccione el año y mes a que corresponde la declaración") so
  per-transaction/monthly 119 filings coexist with the annual consolidation
  (FR-268) without duplicating the same transaction's base across filings —
  each ledger transaction is consolidated exactly once into the annual DJ.
  (LB-001; EV29:EVID-103; EV29:EVID-102)
- **HN-FREP-FR-271:** The system shall net capital losses ONLY against
  capital gains of the SAME fiscal year inside the 119 determination

  compensadas contra ganancias de capital del mismo ejercicio*) — netting

  losses never enter a later year's 119. (LB-001; EV29:EVID-102)
- **HN-FREP-FR-272:** The system shall display, per GC transaction, the

- **HN-FREP-FR-273:** The system shall gate the 119 event ledger on the

### 3.3 Código 152 — Impuesto sobre Tradición de Bienes Inmuebles

- **HN-FREP-FR-283:** The system shall compute the *Impuesto sobre
  Tradición* (onerous real-estate transfer tax, código 152) at 1.5% of the
  transaction value where the base = the HIGHER of market value or
  cadastral value (*el valor de mercado o valor catastral, el que sea
  mayor*), falling back to the declared value when no cadastral value
  exists, floored by the *folio real* appraisal reference (D. 82-2004
  Art. 140, unacquired — floor check enforced only when a folio-real value
  is available, OQ-012); this tax is DISTINCT from and may attach
  alongside the ISR GC 10% on the same transfer (GC event routing consumed
  by id from taxation/03 HN-TAX-FR-100). (LB-006; LB-001; EV29:EVID-106)
- **HN-FREP-FR-284:** The system shall assign the 152 tax burden to the
  *tradente* (transferor/seller — "El tradente del inmueble, a cuyo cargo
  estará el pago del impuesto") with the filing/payment clock of the THIRD
  day counted from the authorization date of the *escritura matriz* (master
  deed) ("enterará dentro del tercer día, contado desde la fecha de
  autorización de la escritura matriz"), and shall compute the late fine
  of twenty percent (20%) of the tax for missing that term ("sancionada
  con una multa equivalente al veinte por ciento (20%) del valor del
  impuesto"). (LB-006; EV29:EVID-106)
- **HN-FREP-FR-285:** The system shall generate the refund claim when a

## 6. Acceptance Criteria

- **AC-001:** Given a GC disposal with agreed value L100,000, market value
  L120,000, mejoras L10,000 and legalization costs L5,000, then the 119
  base = 120,000 − 10,000 − 5,000 = L105,000 and the tax = L10,500 (10% by
  id) (FR-272).
- **AC-002:** Given perception of the agreed value on 2026-03-10, then the
  payment deadline = 10 días hábiles later on the HN business-day calendar
  and a Boletín de Pago Libre 119 is generated; the transaction also enters
  the FY2026 annual DJ due 2027-04-30 exactly once (FR-267, FR-268,
  FR-270).
- **AC-003:** Given disposal of the taxpayer's habitual dwelling, then no
  119 event ledger row is created; given disposal of trading stock in
  habitual giro, then the transaction routes to the ordinary ISR track
  (FR-273).
- **AC-004:** Given a FY2026 GC loss of L30,000 and a FY2026 gain of
  L80,000, then the 119 determination nets to L50,000 × 10%; given the same
  loss with all gains occurring in FY2027, then the loss is NOT netted and
  the 2027 determination ignores it (FR-271).
- **AC-005:** Given a non-resident selling real estate to a resident
  buyer, then the buyer-retention record computes 4% of the transmission
  value (never 2%), shows the `46_ OQ-1` conflict flag, and exports to the
  código 138 eventual filing owned by file 02 (FR-274).
- **AC-006:** Given a State entity paying for purchased rights, then the
  10% State-as-payor retention appears as a crédito (pagos realizados) in
  the 119 credit panel, reducing the annual impuesto a pagar (FR-275).
- **AC-007:** Given an raffle prize recorded on the premios line, then it
  classifies as GC per the Reglamento Art. 32 citation (OQ-013 flag); given
  a Lotería Nacional de Beneficencia prize, then it is excluded per ISR
  Art. 10.e consumed by id (FR-276).
- **AC-008:** Given a ZOLITUR share transfer over property in Roatán, then
  the 120 engine applies 4% on (ingresos − deducciones); given the same
  asset located in the Cayos Cochinos archipelago, then código 120 does not
  apply and the event routes to the general GC tracks (FR-277, FR-278).
- **AC-009:** Given a 120 filing with the resolución number left empty,
  then the wizard blocks advancement to the next section; given all
  Sección A fields completed, then Sección C auto-computes utilidad × 4%
  and Sección D credits render read-only (FR-279, FR-280).
- **AC-010:** Given the 120 cadence config, then the Apr-30 dated row is
  the only enforced deadline while the per-transaction clock shows as
  informational, and the `47_ OQ-3` unpinned flag is visible on the config
  (FR-282).
- **AC-011:** Given a tradición with market L500,000 and catastral
  L450,000, then the 152 base = L500,000 and tax = L7,500; given no
  catastral value and declared L500,000, then base = declared value; given
  a folio-real appraisal of L550,000 on file, then the floor lifts the base
  to L550,000 (1.5% = L8,250) (FR-283).
- **AC-012:** Given an escritura matriz authorized 2026-05-01, then the
  152 payment deadline = 2026-05-04 (within the third day) borne by the
  tradente; given payment on 2026-05-10, then a 20% fine on the tax is
  computed (FR-284).
- **AC-013:** Given the contract rescinded for just cause on month 5 with
  tax L7,500 paid, then a SAR refund petition is generated; given
  rescission on month 7, then no refund workflow opens (FR-285).
- **AC-014:** Given an anonymous user reaching OVI Trámites → Impuesto
  sobre Tradición, then the declaration is filed without login, RTN entry
  auto-fetches names, captcha is required, and the boletín is generated
  before payment (FR-286, FR-287).
- **AC-015:** Given an elective revaluation with increment L1,500,000, then
  SER-154 computes 6% = L90,000 pago único y definitivo (never 10%), the
  perito reference is mandatory, and the exoneración amount field stays
  disabled until a resolution number is entered (FR-290..FR-292).
- **AC-016:** Given a SER-154 filing attempt with no deadline config row
  loaded, then the declaration files successfully but deadline-enforcement
  alerts are suppressed with the `49_ OQ-3` config-gap flag shown
  (FR-293).
- **AC-017:** Given a 119 and a 120 declared AND paid for FY2026, then
  their bases auto-flow into the 102 Sección B no-gravados lines
  (precondition met) and into 103 as read-only linked values; given a 119
  declared but unpaid, then the flow is withheld (FR-295).
