## Notes

- File `14_Ley_Servicios_Internacionales.pdf`: an earlier version of this
  document was found unconstitutional during prior analysis and was replaced
  with Decreto 431 (2007); its Reglamento (Decreto 131) is file `17b_`.
- Numbering gaps (21, 23, 24, 28) are intentional — those documents were not
  carried over from the prior project. New acquisitions continue the sequence
  after the highest existing number (currently 52).
- **2026-08-16 update (files 44-52):** the current MH official set postdates
  most tuky-era documents. Superseded files are RETAINED (they are cited Legal
  Basis for evidence already collected); requirement synthesis must prefer the
  newest source per document and record the supersession. Key changes:
  Normativa v2.0, Manual Tecnológico v2.0, catalogs re-versioned to v1.1
  (replacing the Sistema de Transmisión catalogs, incl. CAT-023 substitution
  and new CAT-038+), JSON schema version bumps, and two NEW event types
  (Evento de Operaciones Especiales `fe-eop-v1`, Evento de Retorno
  `fe-eret-v1`).
- `schemas/` (13 JSON, 2022) superseded by `52_Json_Schemas_DTE_Eventos_2026-08-11.zip`
  (extract per-version to scratch when reading; do not modify sources).
- When adding a document: continue the numeric sequence, name by content
  (version + date when known), place it in this directory, and add a registry
  row with provenance.
