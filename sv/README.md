# El Salvador (SV)

Odoo localization requirements for El Salvador, including electronic
invoicing (facturación electrónica).

- **Tax authority:** Ministerio de Hacienda (MH) — https://www.mh.gob.sv
- **Takumi proof of concept:** not started.
